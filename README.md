# AI Demand Forecasting: Stakeholder Engagement & Change Management Plan

An enterprise change management and communication framework designed for deploying an AI-driven demand forecasting engine across a textile manufacturing mill in Coimbatore, Tamil Nadu.

## 📌 Project Overview
Deploying predictive models into established manufacturing workflows frequently encounters behavioral resistance and departmental misalignment. This project addresses the operational transition by establishing:
- **Augmented Intelligence (Human-in-the-Loop)** governance preserving planner decision authority.
- **Mendelow's Power-Interest Matrix** mapping across 8 key stakeholder groups.
- A **12-Week Phased Communication Calendar** (Alignment, Parallel Run, Assisted Go-Live).
- Multi-tiered messaging including **Tamil-language notices** for shop-floor loom operators.
- A three-tiered **Escalation Matrix** with recovery playbooks for early model errors and supplier sync disruptions.
- A bi-weekly **Quantitative Sentiment Scoring Model (1–5 scale)** with automated intervention triggers.

## 📂 Repository Structure
- `docs/`: Complete submission-ready project reports (`.docx`).
- `data/`: Fortnightly stakeholder sentiment tracking data (`.csv`).
- `scripts/`: Python audit scripts for automated stakeholder sentiment monitoring.
- `templates/`: Production-ready communication templates tailored for executive, operational, technical, and factory-floor audiences.

## 🎯 Measurable Outcomes
- Planners transitioned from **Score 1 (Actively Resistant)** to **Score 3 (Neutral/Compliant)** by Week 8.
- Sales transitioned from **Score 2 (Skeptical)** to **Score 3 (Neutral)** by Week 8.
- Maintained **≥ 90% attendance** across all weekly planner co-design clinics.
